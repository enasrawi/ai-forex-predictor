# EUR/USD AI Forex Predictor

A prototype progressive web app for experimental short-term EUR/USD forecasts, with 15-minute, 30-minute and 1-hour horizons.

The application is configured for EUR/USD only. The backend accepts EUR/USD requests and rejects other currency pairs.

## Important

Forecasts are experimental, may use delayed or incomplete market data, and are not financial advice. The current prototype uses Yahoo Finance through yfinance; free data can be delayed or rate-limited. Do not rely on forecasts to make trading decisions.
